# ✦ Modelo Comercial - Clínica de Estética Avançada & Rejuvenescimento

Site modelo de altíssimo padrão visual e técnico (**Editorial Luxury**), desenvolvido com foco total em conversão e facilidade de personalização rápida para revenda direta a clínicas de estética, biomédicas, dermatologistas e cirurgiões plásticos.

## 🚀 Como Personalizar para o Seu Cliente em 2 Minutos

Todo o site foi programado para puxar as informações essenciais de um único arquivo: **[`config.js`](file:///c:/meu-projeto/clientes/estetica-modelo/config.js)**.

Para entregar o site ao seu cliente:
1. Abra o arquivo [`config.js`](file:///c:/meu-projeto/clientes/estetica-modelo/config.js).
2. Altere os campos:
   - `clinicName`: Nome da clínica (Ex: "Clínica Dra. Juliana Ramos").
   - `whatsapp`: Número com DDD (Ex: "5511999998888").
   - `specialist`: Nome da profissional, título, número de conselho (CRM/CRBM) e minibiografia.
   - `address`: Endereço completo da clínica.
   - `mapsEmbedUrl`: Link do Google Maps da clínica do cliente.
3. Se quiser trocar as fotos, basta substituir os arquivos na pasta [`assets/images/`](file:///c:/meu-projeto/clientes/estetica-modelo/assets/images):
   - `hero-aesthetic.jpg` (Fachada/sala principal)
   - `specialist.jpg` (Foto profissional da responsável técnica)
   - `treatment-face.jpg` e `treatment-body.jpg` (Procedimentos)
   - `skin-before.jpg` e `skin-after.jpg` (Casos reais antes e depois)
